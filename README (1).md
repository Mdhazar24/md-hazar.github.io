## 🎫 02 — Incident & Ticket Workflow

A realistic incident workflow:

```text
NEW → TRIAGE → ASSIGNED → INVESTIGATING → RESOLVED → CONFIRMED → CLOSED
```

Fields include ticket ID, category, priority, symptoms, troubleshooting, owner, SLA, escalation reason, resolution and closure notes.

## 📱 03 — QR Pickup Verification

A prototype:

```text
READY → TOKEN GENERATED → SCAN → VERIFY → PICKUP CONFIRMED → EVENT LOG
```

We will test verification time, failed scans, duplicate attempts and successful confirmations.

## 🧠 04 — Support Root-Cause Engine

Instead of only counting tickets:

```text
Raw Tickets
 ↓
Normalize
 ↓
Group Similar Issues
 ↓
Find Recurring Patterns
 ↓
Hypothesis
 ↓
Process Recommendation
 ↓
Measure Change
```

Observed data, analysis, hypotheses and recommendations will be clearly separated.
