# MD Hazar Portfolio

A one-page GitHub Pages portfolio for MD Hazar.

## Publish
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html` and `MD-HAZAR.pdf`.
3. In the repository, open Settings → Pages.
4. Select Deploy from branch → main → root.
5. Save and open the published URL.

The project descriptions marked as product concepts/case studies are intentionally presented as proposals rather than claimed implementations.
